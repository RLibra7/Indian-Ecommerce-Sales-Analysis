# Indian E-Commerce Sales & Profitability Analysis

## Project Overview
This project analyzes Indian e-commerce sales data to understand sales performance, product profitability, customer order distribution, and monthly trends. The goal is to identify profitable product categories, loss-making sub-categories, and regional sales patterns.

## Tools & Technologies
- **Microsoft Excel:** Data inspection, cleaning, calculations, and initial analysis
- **MySQL:** Data analysis using SQL queries, joins, aggregations, and profitability analysis
- **Power BI:** Interactive dashboards, KPIs, and visualizations

## Key Performance Indicators (KPIs)
- **Total Sales:** ₹431,502
- **Total Profit:** ₹23,955
- **Total Quantity Sold:** 5,615
- **Total Orders:** 500
- **Overall Profit Margin:** 5.55%

## Key Insights
- **Electronics** generated the highest sales, totaling ₹165,267.
- **Clothing** generated the highest category profit of ₹11,163.
- **Furniture** had the lowest category profit margin, approximately 1.81%.
- **Tables** recorded a loss of ₹4,011.
- **Electronic Games** recorded a loss of ₹1,236.
- Madhya Pradesh recorded the highest sales among the states in the dataset, totaling ₹105,140.

## Dashboard Pages
### 1. Sales Overview
Highlights total sales, profit, quantity sold, order count, sales by category, sales by state, and monthly sales trends.

### 2. Product Performance
Analyzes sales, profit, and quantity across product categories and sub-categories.

### 3. Profitability Analysis
Examines category-level profit margins and monthly profit trends.

- `06_Screenshots` — Dashboard screenshots

## Conclusion
This project demonstrates how Excel, MySQL, and Power BI can be used together to analyze sales data, identify profitability issues, and communicate actionable business insights through dashboards.
